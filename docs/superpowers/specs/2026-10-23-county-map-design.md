# 台灣地圖金錢熱力圖（依公司總部縣市）— 設計規格

- 日期：2026-10-23
- 狀態：依 docs/goal-prompt.md 的定案實作（子項目 ③）
- 目的：從「地理」維度看錢流到哪裡，例如桃園、新竹的科技聚落和臺北的金融業各分到多少成交值。

## 1. 資料

- 公司地址：
  - 證交所 OpenAPI `t187ap03_L`（上市，中文住址）。
  - 櫃買中心 OpenAPI `mopsfin_t187ap03_O`（上櫃，**只有英文地址**）。
- 縣市判斷（`sources/company_address.py`），不做鄉鎮或地理編碼，依序嘗試：
  1. 地址中最早出現的完整縣市名（「台／臺」「巿／市」先統一）。
  2. 園區名：新竹科學園區 → 新竹市、南部科學園區 → 臺南市、中部科學園區 → 臺中市。
  3. 鄉鎮市與新北各區：彰化市 → 彰化縣、板橋區 → 新北市、「北市」 → 臺北市。
  4. 英文：去掉空白和符號後比對（處理「Hsin-Chu」「Tao Yuan」「DistrictTaoyuan」），新北各區和新竹縣鄉鎮先於「Taipei」「Hsinchu」比對，也收錄常見錯字。
  5. 海外（開曼、中國、越南、泰國…）歸「海外」。
  6. 最後用郵遞區號前三碼。
- 實測（2026-10-23）：1,991 家公司中，能判斷縣市 1,948 家，海外 38 家，無法判斷 5 家。
- 快取：重用 `ConceptLoader`，快取檔 `data/counties_cache.json`，7 天更新一次。
- 地圖：`static/geo/tw-counties.geo.json`。
  - 由 taiwan-atlas 2021.9.20 的 `counties-10t.json` 轉成 GeoJSON，座標取到小數 3 位，縣市名稱統一用「臺」。
  - taiwan-atlas 是 MIT 授權；原始資料是內政部村里界圖，屬政府資料開放授權條款第 1 版。授權全文見 `static/geo/LICENSE-taiwan-atlas.txt`。
  - 22 個縣市與解析器的縣市清單完全一致（pytest 檢查）。

## 2. API

- `GET /api/counties/status`：載入狀態。
- `GET /api/groupings/county`：代號 → [縣市]。

## 3. 前端（`static/js/countymap.js`）

- 純函式：
  - `aggregateCounties(stocks, countyByCode)`：只算普通股，每個代號只算一次；回傳每縣市的家數、成交值總和、市值加權漲幅、成交值前 3 大個股，以及海外與無法判斷的家數。
  - `buildMapOption`、`countyListHtml`、`turnoverColor`。
- 顏色可切換：
  - 「成交值總和」用平方根色階，避免臺北市把其他縣市都壓成同一色。
  - 「市值加權漲幅」用紅漲綠跌，±3% 為全色。
  - 選擇存在 localStorage。
- 版面：地圖在左（框住台灣本島＋澎湖，可拖曳縮放），縣市排行表在右（家數、成交值、占比、漲跌）。滑過表格列時，地圖會標示該縣市。
- 即時頁：頂列「熱力圖／台灣地圖」切換主畫面，套用目前的市場、ETF、門檻篩選，選擇會記住。
- 歷史頁：G 之後的 H 面板，跟著選中的日期。分組不是官方產業時，另外抓當天全市場資料，地圖永遠呈現全市場。
- 註記會列出依縣市彙總的家數、海外家數與地址無法判斷的家數。

## 4. 驗收

- 22 縣市都有對應（地圖檔與縣市清單一致）。
- 即時與歷史地圖都能顯示並切換顏色；歷史頁換日期時地圖跟著換。
- 地址無法判斷的家數顯示在畫面註記中。
